# Engineering research

Name the decision and the fact it depends on. Check the repository and its pinned versions first. Stop if those sources answer the question.

Check the primary source for the relevant version or target environment. If the source does not answer the question, run a small check in the target environment when possible.

Record the finding, its source or check result, and how it affects the decision. State what remains unverified.
